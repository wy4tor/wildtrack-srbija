# WILDTRACK SRBIJA

Digitalni dokumentarni arhiv prirode Srbije. Slogan: *Divlja Srbija. Priroda koja ima svoju priču.*

Trenutno stanje: jedna samostalna stranica (`index.html`) sa pet pogleda (Početna, Priroda Srbije, Divlje životinje, Galerija, O projektu). Fotografije su ugrađene u HTML.

## Pokretanje
Otvorite `index.html` u pregledaču.

## Sledeći koraci
- Prebaciti u Next.js / TypeScript / Tailwind sa odvojenim stranicama
- Fotografije izdvojiti u fajlove (WebP, srcset)
- sitemap.xml, robots.txt, canonical, BreadcrumbList
- Proveriti podatke o vrstama i statusu zaštite prema izvorima
